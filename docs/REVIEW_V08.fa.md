# بازبینی محصول و تجربه کاربری — نسخه ۰.۸

هدف این بازبینی، روشن شدن چهار تصمیم برای خریدار است: مدل چه کاری می‌کند،
چطور به آن دسترسی پیدا می‌کنم، مبلغ مربوط به چه میزان استفاده است و قدم بعدی چیست.
جایگاه اصلی محصول همچنان بازار مدل‌های فارسی است؛ مدل‌های عمومی و اجاره GPU
در دسترس می‌مانند. مبنای قبلی محاسبه مصرف تغییر نکرده است.

## اصلاح‌های انجام‌شده

| بخش | ایراد | اصلاح |
|---|---|---|
| دسته‌بندی | ردیف اجباری با متن‌های بلند، اسکرول افقی و گزینه‌های بریده | شبکه چهارستونه و در موبایل دوستونه؛ عنوان کوتاه و امکان شکستن متن |
| منوی اصلی | مقصدهای زیاد با اهمیت ظاهری یکسان | چهار مقصد اصلی؛ انتقال نشان‌شده‌ها، درخواست‌ها و سابقه به «فعالیت‌های من» |
| ابتدای صفحه | بنرها و کنترل‌های تکراری قبل از نتایج | معرفی کوتاه، انتخاب کاربرد، روش استفاده و فیلترها؛ دعوت سازنده بعد از نتایج |
| کارت محصول | تصویر بلند، فاصله‌های ناهماهنگ و تکرار | تصویر کوتاه‌تر، فاصله‌های منظم، قیمت برجسته و واحد خوانا |
| ترتیب قیمت | انتخاب ضمنی یک کاربرد بدون تصمیم کاربر | انتخاب کاربرد در یک پنجره کوتاه؛ سپس ارزان‌ترین یا گران‌ترین با مصرف یکسان |
| جستجو | محدود بودن به عنوان و متن کوتاه | جستجو در مدل پایه، زبان و اصطلاح‌های رایج ASR، TTS، OCR و RAG |
| نتیجه خالی | احتمال برداشت اشتباه از نبودن مدل در کل بازار | نمایش نتیجه‌های موجود در بازار دیگر و لینک مستقیم به آن‌ها |
| فیلترهای تخصصی | نمایش ظرفیت متن برای گفتار و تصویر | نمایش فقط فیلد مرتبط با کاربرد یا حافظه GPU |
| عرضه‌کننده | نادیده گرفتن مدل‌هایی که فقط فایل دارند | اعمال فیلتر ارائه‌دهنده روی پیشنهادهای API و مجوز فایل |
| دریافت مدل | ابهام در تفاوت API و فایل | برچسب «آنلاین با API» و «اجرا با فایل مدل»، همراه راهنمای کوتاه |
| مجوز | دیده نشدن محدودیت استفاده غیرتجاری تا ورود به محصول | برچسب مجوز غیرتجاری روی کارت مدل مربوط |
| صفحه تک‌فروشنده | تکرار عدد یکسان در بازه قیمت و بخش خالی فروشندگان | تعرفه در بالای صفحه؛ حذف بازه تکراری و بخش خالی |
| مشخصات | فیلدهای مبتنی بر چت برای همه مدل‌ها | مشخصات متناسب با کار، زبان، نسخه و روش دریافت |
| متن‌ها | عبارت‌های طولانی و نامشخص | عنوان‌های متداول فارسی، توضیح روشن واحد قیمت و قدم بعدی |
| فرم سازنده | از دست رفتن کار نیمه‌تمام پس از تغییر صفحه | نگهداری خودکار فرم در همین مرورگر و بازیابی هنگام بازگشت |
| درخواست خرید | خروجی صرفا فنی | فایل متنی خوانا برای درخواست، در کنار JSON حاوی جزئیات کامل |

## تصمیم‌های محصول

- دقیقه صوت، صفحه سند، میلیون توکن و مجوز یک‌باره با هم رتبه‌بندی نمی‌شوند.
- یک مدل می‌تواند هم API داشته باشد و هم فایل قابل دریافت. نسخه و هویت مدل مشترک است؛ قیمت و شرایط خرید جدا هستند.
- دریافت وزن‌ها به معنی خرید مالکیت مدل یا داده آموزشی نیست. حقوق تجاری، تغییر مدل، بازنشر و پشتیبانی کنار قیمت می‌آیند.
- عدد پایداری فقط برای سرویس API و GPU نمایش داده می‌شود؛ فایل مدل سرویس آنلاین نیست.
- درخواست خرید و معرفی مدل، ذخیره محلی و خروجی فایل دارند. هیچ متن موفقیتی ادعای ارسال، پرداخت یا انتشار آنلاین نمی‌کند.
- جستجو در بازار فارسی نقطه شروع است؛ اگر نتیجه مناسب در مدل‌های عمومی یا GPU باشد، مسیر رسیدن به آن بسته نمی‌ماند.

## بررسی فنی

۴۳ آزمون پایتون، ۱۲ آزمون منطق رابط، ۲ بررسی ساختار CSS، ۶۲ مسیر محصول و
۴۹ سناریوی تعاملی در DOM عبور کرده‌اند. سه سناریوی محاسبه مصرف دلخواه نیز
با خروجی واقعی پایتون بررسی شده است. هزینه، ترتیب پیشنهادها، حداقل اعتبار
و فرض‌های هر ۱۸۶ حالت مصرف با نسخه ۰.۷ یکسان مانده‌اند.

فایل HTML همه استایل‌ها، فونت‌ها و تصاویر لازم را داخل خودش دارد و برای
باز شدن از روی فایل، درخواست شبکه نمی‌فرستد. لینک سایت ارائه‌دهنده به اینترنت نیاز دارد.

## موارد باقی‌مانده برای راه‌اندازی واقعی

بررسی تصویری در مرورگر واقعی، موبایل و مسیر کامل صفحه‌کلید در این محیط انجام
نشده است. بررسی DOM و قواعد CSS جای این مرحله را نمی‌گیرد.

حساب کاربری، ذخیره مرکزی، ارسال درخواست، پرداخت، تحویل خصوصی وزن‌ها و پایش
زنده سرویس هنوز اتصال عملیاتی ندارند. داده‌های نمایشی پایداری طبق درخواست
پروژه حفظ شده‌اند؛ این اعداد حاصل پایش مستقل نیستند. فایل‌های خصوصی، کلید API
و داده آموزشی نباید وارد فرم معرفی مدل شوند.
