# راهنمای مرور نسخه ۰.۱۳

۱. فایل HTML را باز کنید. صفحه اصلی «مدل‌ها و API» است. دسته‌های کاربردی افقی
پیمایش می‌شوند. «مدل‌های اختصاصی فارسی» و «اجاره GPU» مسیرهای جدا دارند.

۲. بالای فهرست، مصرف را تنظیم کنید و «اعمال مصرف» را بزنید. یک بارگذاری کوتاه نمایش داده می‌شود و قیمت‌ها در همان موقعیت صفحه تغییر می‌کنند. مقدار ورودی و خروجی
برای هر درخواست است؛ تعداد درخواست در روز جدا وارد می‌شود. سپس کاربرد را انتخاب کنید و روی «ارزان‌ترین» یا «گران‌ترین» بزنید.
قیمت‌ها برای مصرف یکسان مقایسه می‌شوند. تعرفه ورودی و خروجی، مجوز یک‌باره و
حداقل شارژ حساب مفهوم‌های جدا هستند.

در روش پردازش، «دسته‌ای (Batch)» را برای مقایسه تعرفه پردازش غیرفوری انتخاب کنید.
زمان تحویل و سقف درخواست هر دسته در پیشنهاد فروشنده آمده است. مصرف دلخواه API
در فایل HTML هم بدون سرور کار می‌کند.

پایین نتایج، شماره صفحه و تعداد نتیجه در صفحه را انتخاب کنید. جستجو و فیلترها
هنگام رفتن به صفحه بعد حفظ می‌شوند.

۳. صفحه مدل با پیشنهاد مناسب و ارزان‌تر آغاز می‌شود. قیمت سایر ارائه‌دهندگان
پایین‌تر است. فیلتر ارائه‌دهنده و SSH قابل برداشتن است. تغییر این فیلترها،
مصرف انتخابی شما را عوض نمی‌کند.

۴. در مدل دارای فایل، بین API و دریافت یا خرید وزن‌ها جابه‌جا شوید. مجوز،
حقوق استفاده، سخت‌افزار و پشتیبانی را در مسیر فایل ببینید. هر مربع پایداری
یک روز از سرویس API یا GPU است؛ فایل مدل پایداری سرویس ندارد.

۵. محصولات را نشان کنید یا حداکثر سه مورد را به مقایسه ببرید. در نشان‌شده‌های
ترکیبی، پیش از مرتب‌سازی قیمت، کاربرد را انتخاب کنید. جدول مقایسه برای مدل‌های
هم‌کاربرد، هزینه مصرف یکسان را هم نشان می‌دهد.

۶. برای پیشنهادهای دارای درخواست، مشخصات خود و کاربرد را وارد کنید. درخواست
ذخیره‌شده در «فعالیت‌های من» قابل مشاهده، ویرایش و دریافت است. ویرایش، قیمت و
شرایط اولیه را حفظ می‌کند. دریافت متن بدون ذخیره هم از همان فرم ممکن است.

۷. «معرفی مدل» برای آماده کردن مشخصات مدل شخصی یا شرکتی است. API، فایل یا هر
دو را انتخاب کنید. پیش‌نویس ناقص هم قابل دریافت است. ذخیره و خروجی این فرم،
به معنی انتشار عمومی یا ارسال درخواست نیست.

HTML تمام فونت‌ها و منابع لازم را همراه دارد. لینک سایت ارائه‌دهنده یا مخزن
مدل برای باز شدن به اینترنت نیاز دارد. درخواست‌ها و پیش‌نویس‌ها در همان مرورگر
نگه داشته می‌شوند. اگر ذخیره مرورگر ممکن نباشد، پیام مشخص و مسیر دریافت فایل دارید.
