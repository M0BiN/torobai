# بازبینی نسخه ۰.۱۰

## نگاه خریدار

نوار پایداری در تصویر، شبیه خط پیشرفت بود و جزئیات مفیدی نداشت. حالا هر مربع
یک روز را نشان می‌دهد؛ بازه تاریخ، راهنمای رنگ و درصد پایداری مشخص است.
جزئیات روزها با باز کردن بخش متنی هم خوانده می‌شود و به رنگ یا حرکت ماوس وابسته نیست.

مدل‌های فارسی و مدل‌های تصمیم‌گیری که فقط فایل داشتند، پیشنهاد API هم دارند.
سه شرکت «ابر نارون»، «رایان‌مدل» و «سپیدار هوش» به فهرست اضافه شدند. برای هر
هفت مدل دارای مجوز پولی، API سازنده همان مدل هم وجود دارد. تب فایل مدل،
قیمت یک‌باره و شرایط مجوز را نشان می‌دهد؛ تب API، قیمت ارائه‌دهندگان را.

## نگاه توسعه‌دهنده

۳۵ پیشنهاد API اضافه شد. شرکت‌ها و پیشنهادهای تازه، داده ساختگی برای ارائه
محصول هستند و در داده و مستندات مشخص شده‌اند؛ اتصال زنده یا همکاری واقعی
ادعا نشده است. ۳۰ مقدار روزانه هر پیشنهاد، میانگینی برابر با درصد کلی دارد.
داده قبلی پایداری واقعی دست‌نخورده است. HTML همچنان تمام منابع را همراه دارد.

مجوز غیرتجاری ParsinLU حفظ شد. دسترسی پژوهشی آن رایگان و محدود به سقف مشخص
است؛ مصرف بالاتر در محاسبه رد می‌شود. محدودیت‌ها در فرم و فایل درخواست می‌مانند.

## نگاه مدیر محصول

خریدار می‌تواند برای همان مدل، هزینه API چند ارائه‌دهنده را ببیند و به مسیر
دریافت فایل برود. سازنده و میزبان با هم اشتباه نمی‌شوند. هیچ مجوز خرید وزن
به معنی واگذاری مالکیت یا دریافت سرویس میزبانی نیست. مبنای مقایسه و قیمت‌های
قبلی حفظ شدند؛ صفحه اول و اسکرول دسته‌ها هم تغییر نکردند.

آزمون محاسبات، داده روزانه، مسیرها و نسخه HTML مستقل انجام شد. نمایش واقعی
در مرورگر، موبایل و تعامل صفحه‌کلید هنوز در این محیط بررسی نشده است.
