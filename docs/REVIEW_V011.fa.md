# بازبینی کامل نسخه ۰.۱۱

کد، داده‌ها، مسیر خرید، فرم‌ها، فیلترها، مقایسه و خروجی HTML بررسی شدند.
اصلاحات روی خطاهای مشخص متمرکز است؛ نام، صفحه اول، مبنای قیمت و مربع‌های
پایداری نسخه قبل حفظ شده‌اند.

| بخش | ایراد پیدا‌شده | اصلاح |
|---|---|---|
| صفحه محصول | فیلتر ارائه‌دهنده و SSH از فهرست قبلی به صفحه نامرتبط منتقل می‌شد | فیلترها در لینک همان محصول ثبت می‌شوند |
| تک‌ارائه‌دهنده | گزینه برداشتن فیلتر داخل بخش مخفی فروشنده‌ها بود | کنترل فیلتر همیشه بیرون آن بخش دیده می‌شود |
| تغییر فیلتر | بازسازی صفحه می‌توانست مصرف انتخابی را به حالت اولیه برگرداند | فیلتر پیشنهادها بدون تغییر مصرف اعمال می‌شود |
| API و فایل | فیلتر میزبان API می‌توانست فایل سازنده را پنهان کند | تب فایل، عرضه‌کننده مجوز را مستقل انتخاب می‌کند |

## نتیجه بررسی

۵۰ آزمون Python، ۱۷ آزمون ابزارهای JavaScript و ۳ بررسی ساختار CSS موفق بودند.
هر ۶۲ مسیر محصول و سناریوهای نسخه HTML مستقل بررسی شدند. حالت‌های لینک خراب،
ذخیره غیرفعال، خطای محاسبه، ویرایش درخواست، خروجی ناقص و جابه‌جایی روش دریافت
نیز در بررسی‌ها پوشش داده شدند. نسخه در حال اجرا هم با داده محاسبات Python بررسی شد.

تمام فایل‌های داده و ۱۸۶ رکورد کامل مصرف، شامل ۴۶۸ محاسبه پیشنهاد، با نسخه
۰.۱۰ یکسان‌اند. هیچ قیمت، مجوز، شرکت، مدل یا مقدار پایداری عوض نشده است.

نمایش واقعی در مرورگر، لمس موبایل، تعامل واقعی صفحه‌کلید و باز کردن فایل در
Windows در این محیط بررسی نشده است. بررسی ساختار و اجرای DOM جای این مرحله
را نمی‌گیرد. پرداخت، تحویل وزن و اتصال زنده به API شرکت‌ها در دامنه این نسخه نیست.
