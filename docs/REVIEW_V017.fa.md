# بازبینی نسخه ۰.۱۷

## تصمیم محصول

torobai جستجو و مقایسه پیشنهادهای عرضه‌کنندگان مدل، API و GPU را انجام می‌دهد.
خرید و دریافت سرویس با عرضه‌کننده است. یک مدل و نسخه، یک صفحه دارد؛ عرضه API
و مجوز وزن‌ها زیر همان هویت باقی می‌مانند. پیش‌فرض صفحه اصلی همچنان مدل‌ها و API است.
ساخت درگاه اجرای API، کیف پول مشترک و مسیریابی درخواست جزو این تغییر نیست.

## از نگاه خریدار

- نام عرضه‌کننده در پیشنهاد ارزان‌تر و بقیه ردیف‌ها به پروفایل او وصل شد.
- پروفایل، محصولات، نوع عرضه، حداقل اعتبار و لینک شرایط را یک‌جا نشان می‌دهد.
  جستجو هم در کل عرضه‌کنندگان و هم در محصولات یک عرضه‌کننده ممکن است.
- هزینه API و مجوز وزن‌ها کنار همان مدل، با دوره پرداخت جدا دیده می‌شوند.
- اقدام خرید مقصد مشخص دارد. عرضه‌کنندگان بدون سایت از درخواست قابل دریافت
  به شکل فایل استفاده می‌کنند؛ لینک خرید ساختگی اضافه نشده است.
- تاریخ ثبت تعرفه، در صورت داشتن داده، و گزارش مغایرت کنار هر پیشنهاد است.
- پیگیری قیمت با همان مصرف، حالت Batch، فیلتر عرضه‌کننده و نسخه ذخیره می‌شود.
  تغییر نسخه مقایسه مبلغ را متوقف می‌کند؛ حذف مدل هم سابقه کاربر را پاک نمی‌کند.
- بخش معرفی محصول فشرده‌تر و شرایط پروفایل در موبایل بازشدنی است.

## از نگاه توسعه‌دهنده

موتور قیمت‌گذاری، داده مدل‌ها و تعرفه‌ها تغییر نکردند. مسیرهای جدید در همان
مسیریاب اضافه شدند. فایل مستقل همه منابع را در خود دارد؛ منبع محلی یا درخواست
شبکه جدید به آن اضافه نشده است. حالت‌های خطا، HTML در ورودی، ذخیره مسدود،
فایل گزارش بدون ذخیره، تغییر نسخه و پیگیری اجاره غیرپیش‌فرض بررسی شدند.

## از نگاه مدیر محصول

پایداری سرویس جای امتیاز یا اعتبار فروشنده استفاده نمی‌شود. امتیاز، نظر مشتری،
تضمین خرید و به‌روزرسانی لحظه‌ای ساختگی اضافه نشد. پیگیری قیمت و گزارش‌ها در
همین مرورگر ذخیره می‌شوند؛ ارسال به پشتیبانی، اعلان بیرونی و همگام‌سازی بین
دستگاه‌ها به زیرساخت متصل نیاز دارند و این نسخه ادعای انجام آن‌ها را ندارد.
تاریخچه بازار از روی سناریوهای مصرف ساخته نشده است.
