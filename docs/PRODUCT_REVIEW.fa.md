# بازبینی محصول — نسخه ۰.۷

## از نگاه خریدار

- صفحه اول روشن می‌کند اینجا بازار مدل‌های فارسی است؛ کاربرد و روش دریافت جدا هستند.
- خریدار گفتار فارسی می‌تواند مدل تلفنی را از مدل عمومی جلسه تشخیص دهد.
- در ترجمه، جهت زبان در کارت و شناسنامه دیده می‌شود.
- صفحه مدل، API را با وزن‌های قابل خرید اشتباه نمی‌گیرد. قیمت مجوز یک‌باره است.
- حقوق استفاده تجاری، تغییر مدل، بازفروش، پشتیبانی و سخت‌افزار کنار خرید قرار دارند.
- مدل عمومی با مجوز غیرتجاری همچنان غیرتجاری نمایش داده می‌شود.

## از نگاه توسعه‌دهنده

- محاسبه پول در پایتون باقی مانده؛ قیمت مجوز وارد مصرف API نمی‌شود.
- رکورد مدل، پیشنهاد API، مجوز وزن‌ها و سازنده جدا هستند.
- مسیر ثبت مدل، پیش‌نویس قابل ویرایش و فایل قابل دریافت دارد.
- متن فرم در پیش‌نمایش ایمن نمایش داده می‌شود و خطای ذخیره پنهان نمی‌ماند.
- داده آموزشی خصوصی و کلید API دریافت نمی‌شود.
- اعداد نمایشی پایداری طبق درخواست کاربر در فایل جدا ذخیره شده‌اند.

## از نگاه مدیر محصول

تمایز اصلی در کشف مدل فارسی و شرایط عرضه آن است. GPU نقش زیرساخت را دارد و
مدل‌های عمومی حذف نشده‌اند. برای جلوگیری از شلوغی، امتیاز و نظر ساختگی، اجرای
زنده غیرواقعی و تظاهر به پرداخت یا انتشار اضافه نشده است.

انتشار مرکزی، پرداخت، صدور کلید API و تحویل محافظت‌شده وزن‌ها هنوز متصل نیستند.
پیش‌نویس و درخواست در مرورگر ذخیره می‌شوند و فایل آن‌ها قابل دریافت است.
بررسی بصری در مرورگر واقعی این محیط انجام نشده است.
