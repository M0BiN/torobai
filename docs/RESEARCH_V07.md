The redesign distinguishes a model card, API deployment and weight license.
Hugging Face documents model cards with language, license, datasets and evaluation;
gated access is a separate permission mechanism. Replicate versions identify a
specific deployable model revision. These support the version/access separation,
not a claim that either service runs this project.

## Three public Persian model cards checked

1. MohammadGholizadeh/whisper-large-v3-persian-common-voice-17: Persian adaptation
   of Whisper Large v3 using Common Voice 17, Apache-2.0. The card currently gates
   file access and says timestamps are not supported. No API seller was added.
   https://huggingface.co/MohammadGholizadeh/whisper-large-v3-persian-common-voice-17
2. persiannlp/mt5-base-parsinlu-translation_en_fa: English-to-Persian mT5 model.
   Published license CC-BY-NC-SA-4.0 is noncommercial; do not attach a fictional
   commercial sale to it. The product explicitly surfaces that restriction.
   https://huggingface.co/persiannlp/mt5-base-parsinlu-translation_en_fa
3. hezarai/crnn-base-fa-v2: Apache-2.0 Persian text recognition for short printed
   text crops. A separate detector is needed for full-page OCR. Do not describe
   this checkpoint as an end-to-end document extraction service.
   https://huggingface.co/hezarai/crnn-base-fa-v2

## Presentation fixtures authorized by the user

Ten private product concepts cover meetings, telephone ASR, both translation
 directions, TTS, printed OCR, invoice extraction, semantic retrieval, sentiment
and customer support. Four publisher identities, their claims, samples, deployment
requirements, nine API rates and seven paid licenses are fictional catalog records.
They are not observed services, partnerships or evaluations. No accuracy scores,
customer reviews, purchase counts or verified badges were fabricated.

Every API/GPU offer has a fixed illustrative uptime value between 99.63 and 99.98
percent in presentation_reliability.json. These values were expressly requested
for presentation. They are not measurements, do not change on refresh and are not
backfilled into the old external evidence. Links to official provider status pages
are navigation destinations, not citations for the illustrative values.

The original provider-reported request-success snapshot remains in reliability.json.
It is not a temporal uptime measure. Weight files instead show local-deployment
conditions, because an undeployed weight file has no service uptime.
