# بازبینی نسخه ۰.۱۹

در تصویر کاربر، کارت‌های بلند API و وزن‌ها و فیلتر تمام‌عرض فضای زیادی پیش
از پیشنهاد قیمت گرفته بودند. انتخاب روش دریافت اکنون یک نوار کوچک با تب فعال
و تعداد پیشنهادهاست. فیلتر قابلیت‌های API کنار آن قرار دارد و پنل آن روی محتوا
باز می‌شود؛ قیمت‌ها پایین نمی‌روند. فاصله اضافی مسیر بالای صفحه هم حذف شد.

بخش‌های بازشونده مثل شرایط عرضه، هزینه، تنظیم مصرف، نمونه مدل، جزئیات پایداری
و بخش‌های مدیریتی از انیمیشن مشترک استفاده می‌کنند. باز شدن ۲۶۰ و بسته شدن
۲۱۰ میلی‌ثانیه است. منو و فیلتر با محو شدن و حرکت کوتاه باز و بسته می‌شوند؛
پنجره‌های گفتگو نیز در هر دو جهت حرکت دارند. کلیک سریع دوباره، حرکت را از
همان وضعیت برمی‌گرداند و ارتفاع ثابت در پایان باقی نمی‌ماند.

Escape، کلیک بیرون پنل، حالت کاهش حرکت و مرورگر فاقد API انیمیشن مسیر مشخص
دارند. هیچ زمان انتظار یا لودینگ به داده آماده اضافه نشده است. محاسبه قیمت،
مبنای مصرف و اسکرول صفحه‌بندی تغییر نکرده‌اند.

بررسی شامل اجرای DOM و رویدادها، چرخه انیمیشن، تغییر جهت، خطایابی خروجی مستقل
و رفتارهای قبلی است. ظاهر پیکسلی و روانی حرکت در مرورگر واقعی بررسی نشده‌اند.
