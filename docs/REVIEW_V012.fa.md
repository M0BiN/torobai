# تغییرات نسخه ۰.۱۲

این نسخه روی خوانایی قیمت مدل‌ها، پشتیبانی از مقایسه Batch و مرور فهرست تمرکز دارد.
ساختار صفحه اصلی، دسته‌بندی افقی، مدل‌های فارسی و مربع‌های پایداری حفظ شده‌اند.

## اصلاحات

| بخش | رفتار جدید |
|---|---|
| لوگوی ارائه‌دهنده‌ها | در ردیف کوچک کارت، فقط لوگوهای موجود نمایش داده می‌شوند. شرکت‌های بدون لوگو از بازار حذف نشده‌اند؛ نام و پیشنهادشان در صفحه مدل هست. |
| مصرف مدل‌ها | بالای فهرست، تعداد درخواست روزانه و توکن ورودی و خروجی قابل تنظیم است. برای صوت، صفحه، تصویر و کاربردهای دیگر، واحد مناسب همان کار دیده می‌شود. |
| قیمت کارت | مبلغ اصلی، هزینه مصرف انتخابی در ۳۰ روز است. دو تعرفه ورودی و خروجی از همان ارائه‌دهنده منتخب نمایش داده می‌شوند. |
| ترتیب قیمت | ارزان‌ترین و گران‌ترین، پس از اعمال مصرف و فیلتر روی تمام نتایج محاسبه می‌شوند. مصرف صوت با تعداد توکن مقایسه نمی‌شود. |
| فایل HTML | مصرف دلخواه API در فایل مستقل هم محاسبه می‌شود؛ فونت، دارایی‌ها و قواعد محاسبه همراه فایل هستند. |
| Batch | روش پردازش عادی یا دسته‌ای قابل انتخاب است. پیشنهادهای Batch تعرفه، زمان تحویل و سقف درخواست هر دسته دارند. نبود تعرفه Batch به قیمت عادی تبدیل نمی‌شود. |
| معرفی مدل | سازنده می‌تواند پشتیبانی Batch، تعرفه، زمان تحویل و سقف درخواست را در پیش‌نویس خود مشخص کند. |
| درخواست خریدار | روش پردازش و تعرفه موثر همان پیشنهاد در درخواست و فایل متنی حفظ می‌شوند. |
| صفحه‌بندی | انتخاب ۲۰، ۴۰ یا ۶۰ نتیجه، شماره صفحه، قبلی و بعدی، بازه نتایج و برای فهرست بلند امکان رفتن به شماره صفحه فراهم است. |
| حفظ وضعیت | آدرس صفحه شامل جستجو، فیلتر، مصرف، روش پردازش و صفحه نتایج است. تعداد نتایج هر صفحه هم در مرورگر نگه داشته می‌شود. تغییر فیلتر یا مصرف به صفحه اول می‌رود. |

## تصمیم‌های محصول

- در فهرست ترکیبی، فرم اولیه برای مدل‌های متنی است؛ این موضوع در همان فرم نوشته شده است. کاربردهای دیگر، مصرف پیش‌فرض متناسب خودشان را دارند. برای تنظیم دقیق هر کاربرد، دسته آن را انتخاب کنید.
- مبنای مقایسه قبلی حفظ شده است. اعتبار لازم برای شروع استفاده، هزینه مصرف و خرید یک‌باره مجوز فایل، با هم جمع نمی‌شوند.
- Batch برای دریافت فوری پاسخ نیست. سقف درخواست هر دسته با کل مصرف ماهانه یکی نیست؛ یک مصرف ماهانه می‌تواند در چند دسته اجرا شود.
- دسترسی به Batch ویژگی پیشنهاد ارائه‌دهنده است. از نام مدل یا پشتیبانی شرکت اصلی نمی‌توان پشتیبانی واسطه را نتیجه گرفت.
- نرخ و شرایط ۷۹ پیشنهاد Batch، داده نمایشی با منشأ مشخص در `batch_terms.json` هستند؛ اطلاعات اصلی قیمت‌ها و مشاهدات قبلی تغییر نکرده‌اند.
- این مسیر مقایسه تعرفه و آماده کردن درخواست دسترسی است. ارسال واقعی کار پردازشی، دریافت کلید API و اجرای مدل به سایت اضافه نشده است.

## بررسی

همه ۱۸۶ سناریوی قبلی و ۴۶۸ محاسبه پیشنهادها از نظر مبلغ، اعتبار اولیه و دلیل کنار گذاشتن پیشنهاد با نسخه ۰.۱۱ یکسان هستند. ۴۱۴۰ حالت عادی و Batch بین محاسبه Python و فایل آفلاین تطبیق داده شده است.

قواعد قیمت، سقف مصرف و تعرفه ورودی بلند در Python ساخته می‌شوند و هر دو مسیر همان قواعد را اجرا می‌کنند. محاسبه فایل مستقل از اعداد صحیح بزرگ استفاده می‌کند و فقط مبلغ نهایی را گرد می‌کند.

آزمون‌های صفحه‌ها با اجرای کد HTML و رویدادها انجام شده‌اند. رندر واقعی مرورگر، لمس موبایل و نمایش Windows در این محیط بررسی نشده‌اند. صفحه‌بندی روی کاتالوگ محدود فعلی انجام می‌شود؛ زیرساخت صفحه‌بندی سمت سرور برای موجودی نامحدود پیاده نشده است.
