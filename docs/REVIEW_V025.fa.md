# بررسی نسخه ۰.۲۵

چت‌بات در پوشه مستقل `chatbot` به پروژه اضافه شده است. فایل دستور توسعه
پیوست‌شده کاربر بدون تغییر در همین پوشه قرار دارد. مسیر اصلی همچنان مدل‌ها
و API است و پنل راهنما خودکار باز نمی‌شود.

## نتیجه پیاده‌سازی

- اتصال پیش‌فرض OpenRouter با مدل `openai/gpt-4.1-mini` و امکان تغییر مدل از
  متغیر محیطی؛ کلید فقط روی سرور است.
- متن آزاد به نیاز ساختاریافته تبدیل می‌شود. کارت‌ها، قیمت‌ها و لینک‌ها از
  کاتالوگ موثر و موتور محاسبه فعلی سایت می‌آیند.
- مسیرهای مدل/API، مدل‌های فارسی، وزن‌ها، GPU، مقایسه عملکرد و عرضه مدل پوشش
  داده شده‌اند. درخواست چندبخشی به انتخاب بخش‌های مستقل هدایت می‌شود.
- سوال درباره روش دسترسی فقط وقتی پرسیده می‌شود که کاربر مشخص نکرده باشد.
  مصرف و بودجه داخل پنل قابل تغییرند؛ مقادیر فرض‌شده آشکارند.
- فیلتر آزمون کدنویسی منتشرشده و سقف هزینه به صفحه نتایج و لینک‌ها اضافه شد.
  نتیجه ناشناخته یا سناریویی مبنای ادعای کیفیت نمی‌شود.
- تغییر نیاز، توقف، تلاش دوباره، خطای اتصال و پاسخ دیررس کنترل شده‌اند.
  تغییر فیلتر پس از رفتن به نتایج می‌تواند با انتخاب کاربر وارد گفتگو شود.
- نسخه HTML با گزینه‌های آماده، قیمت‌ها و فیلترها بدون شبکه کار می‌کند.
  فهم متن آزاد به اجرای نسخه سروری و تنظیم کلید نیاز دارد.

## بررسی‌ها

- ۸۰ آزمون Python: داده و قیمت قبلی، قرارداد OpenRouter، مرز ورودی، خروجی
  نامعتبر، نبود کلید، محدودیت درخواست و منبع فیلتر کدنویسی.
- آزمون جدید چت: انتخاب مرحله‌ای، قیمت یکسان کارت و مقصد، اعداد فارسی، سقف
  صفر و حذف آن، GPU با دوره اجاره، تغییر نیاز، مقایسه مدل‌های نام‌برده،
  مسیر عرضه‌کننده، پاسخ دیررس و ادامه پس از نبود نتیجه.
- آزمون‌های قبلی رابط، ناوبری، Batch، کش، حرکت، بازار و بنچمارک نیز اجرا شدند.
  آزمون خروجی مستقل ۶۲ مسیر محصول و ۸۲ سناریو را بررسی می‌کند.
- تطابق محاسبات Python و JavaScript روی ۴۱۴۰ مورد حفظ شد.

این‌ها آزمون کد، HTTP با پاسخ کنترل‌شده و DOM هستند. اتصال مرورگر به سرور
محلی با خطای اتصال روبه‌رو شد؛ بررسی واقعی پیکسل، انیمیشن و اندازه موبایل
تکمیل نشده است. کلید OpenRouter در محیط تنظیم نبود؛ فراخوانی پولی، کیفیت
فهم فارسی و زمان پاسخ واقعی اندازه‌گیری نشده‌اند.

## محدودیت‌های موثر

چند پیشنهاد عمومی هنوز داده تاییدشده برای ابزار یا سایر قابلیت‌ها ندارند.
ترکیب این شروط ممکن است نتیجه خالی بدهد؛ قابلیت یا منبع تازه‌ای جعل نشده است.
نیازهای فاقد شاهد مثل کیفیت لهجه، مجوز تجاری یا محل پردازش برای بررسی باقی
می‌مانند. نرخ موفقیت دو نوبتی اندازه‌گیری نشده است.

گفتگو فقط تا باز بودن همان صفحه در حافظه می‌ماند. محدودیت نرخ سرور برای یک
پردازه است؛ انتشار با چند worker به محدودیت مشترک در لایه ورودی و سقف هزینه
کلید OpenRouter نیاز دارد. توقف دریافت پاسخ لزوما درخواست پذیرفته‌شده نزد
ارائه‌دهنده را لغو نمی‌کند.
